# Veodee

A modern YouTube playlist manager.

## Features

- Organize videos with custom tags
- Multiple player options (YouTube, Plyr)
- Dark/light theme
- Export/import library
- Responsive design

## Getting Started

```bash
npm install
npm run dev
npm run build
```

## Project Structure

```
public/
└── pre-style.js  # Sets the initial background to prevent a flash of unstyled content

src/
├── components/
│   ├── player/
│   ├── playlist/
│   └── ui/
├── contexts/
├── hooks/
├── lib/
├── pages/
└── types/
```

## Scripts

- `npm run dev` - Start dev server
- `npm run build` - Build for production
- `npm run lint` - Run ESLint
- `npm run preview` - Preview build

## Tech Stack

React 19, TypeScript, Vite, Tailwind CSS, React Router
